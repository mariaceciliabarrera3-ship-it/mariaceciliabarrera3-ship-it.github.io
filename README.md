# 99% IA

Vitrina estática de herramientas propias construidas con asistencia de IA.

- Sin frameworks, sin build step, sin backend.
- Contenido en `data/config.json`, `data/herramientas.json` y `data/servicios.json`.
- Para ponerla en marcha, seguí `MANUAL_PUESTA_EN_MARCHA.md`.

## Estructura

```
index.html
styles.css
app.js
data/
  config.json       ← datos de contacto, redes, aportes, analítica
  herramientas.json ← catálogo de herramientas
  servicios.json    ← servicios que ofrecés
assets/
  favicon.svg
  og-cover.png
robots.txt
sitemap.xml
LICENSE
```
