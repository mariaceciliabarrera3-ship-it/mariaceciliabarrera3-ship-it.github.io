El 1%
El 99% de este código lo escribe la IA. El 1% es mío: plantear el problema, poner a competir a varios modelos, elegir el resultado que sirve, probarlo con datos reales y decidir con qué estado se publica.

Herramientas

Cada una resuelve el mismo problema —tabla a paisaje 3D con variables clave— con una matemática distinta. Los estados son reales: nada acá dice "Activo" si todavía no lo está.

Método

Cómo se construye cada herramienta

Definir el problema

Un dato real que necesita leerse rápido: qué variables importan y por qué, antes de escribir una línea de código.

Construir con IA

Pruebo el mismo problema con más de un modelo cuando conviene comparar enfoques, como en TOPO VCE (vecinos más cercanos) y ToposGraph3D (UMAP).

Probar con datos reales

Cada versión se prueba con tablas reales antes de subir el estado de "En desarrollo" a "Testing" o "Activo".

Publicar en abierto

El repositorio queda público desde el primer commit. El estado que ves acá es el estado real del código, no una promesa.
